# FINAL REFLECTION – MISSION 1 TO 10

Throughout Missions 1 to 10, I learned how to set up and manage cloud infrastructure. I gained practical experience in configuring virtual machines, installing operating systems, managing Linux servers, and understanding network connectivity.

In Mission 10, I applied my knowledge by deploying Ubuntu Server through VirtualBox and using Docker and Docker Compose to run WordPress and MySQL containers. I also configured persistent volumes, secured the server using UFW, and created a Bash script for automated database backups using cron.

One of the challenges I encountered was troubleshooting configuration errors and making sure that the containers and services worked properly. Through this experience, I improved my problem-solving skills and became more familiar with Linux commands and cloud infrastructure management.

Overall, these missions helped me understand the importance of virtualization, automation, security, and proper documentation in managing cloud environments.
