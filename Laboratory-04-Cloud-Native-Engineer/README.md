## Mission 4: The Cloud-Native Engineer

# Mission Overview
In this laboratory activity, I explored the fundamentals of cloud-native engineering by learning the difference between traditional Virtual Machines (VMs) and containers. I used the KillerCoda Docker environment to practice basic Docker commands and deploy an Nginx web server inside a container. I also practiced managing the container lifecycle by listing, stopping, and removing a container. The activity helped me understand how containers provide a lightweight and portable way to run applications.
