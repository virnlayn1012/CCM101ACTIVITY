# Mission 5: Cloud Data Engineer

## Mission Overview
In this laboratory, I learned about cloud storage and the three types of storage: Block Storage, File Storage, and Object Storage. I used Docker and MinIO in the KillerCoda Playground to create an object storage server. I also created a bucket and uploaded a sample file using the MinIO web interface.

## Objectives
*Learn the difference between Block, File, and Object Storage.
* Deploy MinIO using Docker.
* Access MinIO using a web browser and port forwarding.
* Create a bucket and upload a file.
* Document the steps using Markdown.
* Add my work to my GitHub Cloud Computing Portfolio.

## Tools Used
* KillerCoda Playground
* Ubuntu
* Docker
* MinIO
* GitHub
* Web Browser
* Markdown

## Skills Learned
* Using basic Linux commands
* Using Docker to run a server
* Understanding cloud storage
* Creating and using storage buckets
* Uploading files to object storage
* Using port forwarding
* Writing Markdown documentation
* Updating a GitHub portfolio
