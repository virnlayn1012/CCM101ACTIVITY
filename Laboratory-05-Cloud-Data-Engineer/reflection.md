# Mission Reflection

In this laboratory activity, I learned why Object Storage is useful for storing many photos. Object Storage is better for millions of photos because photos are files that do not need to be stored like a normal computer hard drive. It can store a large amount of data and makes it easier for applications to access files. This makes it a good choice for a photo-sharing application.

Docker also made it easier to deploy the MinIO server. Instead of installing and setting up everything manually, I used a Docker command to create the MinIO container. Docker helped me run MinIO in a separate environment and made the setup faster and more organized.

I also learned what a bucket is in cloud storage. A bucket is like a container where objects or files are stored. In this activity, I created a bucket named client-photos and uploaded a sample file into it. This helped me understand how files can be organized in object storage.

Large companies can protect their data in different ways. They can keep copies of data on different servers and locations. They can also use backups and data replication. These methods can help protect files if one physical server crashes or becomes unavailable.

My confidence in using the Linux command line is also improving. At first, I was not very familiar with Docker commands, and I had some problems downloading the MinIO image. I learned that errors can happen and that I need to read the error message carefully. After solving the problem, I became more comfortable using Docker commands and checking containers. This activity helped me understand that practice and patience are important when working with Linux and cloud technologies.
