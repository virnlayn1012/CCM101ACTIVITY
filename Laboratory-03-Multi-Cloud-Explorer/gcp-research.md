## 1. Brief Overview

Google Cloud Platform (GCP) is a cloud platform made by Google. It provides services for running applications, storing data, managing databases, and working with artificial intelligence.

## 2. Global Infrastructure

Google Cloud has data centers in different parts of the world. These are organized into Regions and Zones. This allows users to run their applications in different locations.

## 3. Cloud Management Console

The Google Cloud Console is a website used to manage Google Cloud services. Users can create, change, and check their cloud resources using the console.

## 4. Four Core Services
## Compute Engine

Compute Engine provides virtual computers in the cloud. It can be used to run applications and other programs.

## Cloud Storage

Cloud Storage is used to store files and data. It can store documents, images, videos, and backups.

## Cloud SQL

Cloud SQL is a service for managing databases in the cloud. It helps users store and manage their data.

## Google Cloud VPC

Google Cloud VPC is used to create and manage a private network. It helps connect different cloud resources.

## 5. Three Advantages
* GCP has strong tools for artificial intelligence and machine learning.
* GCP has good support for Kubernetes.
* GCP has cloud locations in many parts of the world.

## 6. Typical Enterprise Use Cases

Companies can use GCP for websites and applications, data storage, databases, artificial intelligence, machine learning, and Kubernetes applications.
