
## 1. Brief Overview

Amazon Web Services (AWS) is a cloud platform made by Amazon. It provides different services that people and companies can use to store data, run applications, and manage their IT needs.

## 2. Global Infrastructure

AWS has data centers in different parts of the world. These are grouped into Regions and Availability Zones. This helps users run their applications in different locations.

## 3. Cloud Management Console

The AWS Management Console is a website where users can manage their AWS services. Users can create, change, and check their cloud resources using the console.

## 4. Four Core Services

### Amazon EC2

Amazon EC2 provides virtual computers in the cloud. It can be used to run websites, applications, and other programs.

### Amazon S3

Amazon S3 is used to store files and data. It can store documents, images, videos, and backups.

### Amazon RDS

Amazon RDS is a service for creating and managing databases. It makes it easier to use a database in the cloud.

### Amazon VPC

Amazon VPC is used to create a private network in AWS. It helps users connect and manage their cloud resources.

## 5. Three Advantages

* AWS has many different cloud services.
* AWS can increase or decrease resources when needed.
* AWS has cloud locations in many parts of the world.

## 6. Typical Enterprise Use Cases

Companies can use AWS to run websites and mobile apps, store files and data, manage databases, and create backup systems.
