# Mission Reflection

## 1. Which cloud infrastructure component do you think is the most important? Why?

I think networking is one of the most important cloud infrastructure components because it connects different resources and allows them to communicate. A server can have enough CPU, memory, and storage, but users and other services still need a network connection to access it. Networking also makes it possible for different parts of a cloud application to work together.

## 2. How does Linux support cloud computing?

Linux provides a reliable environment for running servers and applications in the cloud. In this activity, I used the Linux terminal to inspect different parts of the server instead of relying on a graphical interface. The commands helped me understand how administrators can monitor and investigate cloud-based systems.

## 3. Why is technical documentation important before deploying infrastructure?

Documentation gives engineers a record of the resources and design decisions involved in a system. It can be used as a reference when setting up or troubleshooting infrastructure. It also makes it easier for other members of a team to understand the system.

## 4. What new skills did you learn during this laboratory activity?

I learned how to use several Linux commands for checking hardware and system information. I also learned how compute, storage, networking, and operating systems work together in a cloud environment. Creating Markdown files and organizing evidence in GitHub also gave me more practice with technical documentation.

## 5. How has your GitHub portfolio improved after completing this mission?

My portfolio is now more useful because it contains technical documentation instead of only basic laboratory files. I added an infrastructure investigation, cloud provider comparison, architecture diagram, and reflection. The activity also helped me understand how GitHub can be used to keep technical work organized and show the progress of my learning.
