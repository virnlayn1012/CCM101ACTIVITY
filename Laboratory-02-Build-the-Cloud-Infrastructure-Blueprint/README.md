# Mission 2: Build the Cloud Infrastructure Blueprint

## Mission Overview

This laboratory activity involved examining a Linux server in the KillerCoda environment and identifying the basic resources that make up cloud infrastructure. The investigation covered compute, storage, networking, and the operating system. The activity also included comparing AWS, Microsoft Azure, and Google Cloud Platform and creating a simple cloud infrastructure design.

## Objectives

- Investigate a Linux cloud server.
- Identify compute and storage resources.
- Examine networking information.
- Understand the role of an operating system in cloud infrastructure.
- Compare infrastructure services from major cloud providers.
- Create a basic cloud architecture diagram.
- Practice organizing technical work using GitHub and Markdown.

## Cloud Infrastructure Components

The main components investigated were compute, storage, networking, and the operating system.

The server contained one CPU core and approximately 1.9 GiB of RAM. It also had a 20 GB virtual disk. The server used Ubuntu 24.04.4 LTS and had network addresses assigned to its environment.

## Linux Commands Executed

| Command | Function |
|---|---|
| `cat /etc/os-release` | Displays operating system information |
| `uname -r` | Displays the kernel version |
| `lscpu` | Displays CPU information |
| `nproc` | Displays the number of CPU cores |
| `free -h` | Displays memory information |
| `lsblk` | Displays storage devices |
| `df -hT` | Displays filesystem information |
| `hostname` | Displays the server hostname |
| `hostname -I` | Displays IP addresses |
