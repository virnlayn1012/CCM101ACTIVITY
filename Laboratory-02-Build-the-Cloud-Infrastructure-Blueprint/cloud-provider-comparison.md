# Cloud Provider Comparison

The major public cloud providers provide similar infrastructure services, although the names and specific features of their services differ.

| Infrastructure Component | AWS | Microsoft Azure | Google Cloud Platform |
|---|---|---|---|
| Compute | Amazon EC2 | Azure Virtual Machines | Compute Engine |
| Storage | Amazon S3 | Azure Blob Storage | Cloud Storage |
| Networking | Amazon VPC | Azure Virtual Network | Virtual Private Cloud (VPC) |
| Identity and Access Management (IAM) | AWS IAM | Microsoft Entra ID / Azure RBAC | Cloud IAM |

## 1. Which cloud provider offers the broadest range of services?

AWS is one of the providers known for having a very broad collection of cloud services. Its services cover areas such as virtual machines, storage, databases, networking, security, analytics, and artificial intelligence. This gives organizations many choices when creating cloud solutions.

## 2. Which cloud platform would you recommend for an organization that primarily uses Microsoft products?

Microsoft Azure would be a good choice for an organization that already relies heavily on Microsoft products. Azure is designed to work with Microsoft's technologies and can make it easier to connect existing Microsoft-based systems with cloud services.

## 3. Which platform is widely recognized for Artificial Intelligence, Machine Learning, and Kubernetes services?

Google Cloud Platform is widely recognized for its capabilities in AI, machine learning, and Kubernetes. Google created Kubernetes and provides Google Kubernetes Engine (GKE), while also offering several AI and machine learning services. AWS and Azure also provide strong services in these areas.

## 4. What similarities did you observe among the three cloud providers?

All three providers offer the major infrastructure services needed to build cloud systems. They all provide computing, storage, networking, and identity and access management. Their service names differ, but their basic purposes are often very similar.
