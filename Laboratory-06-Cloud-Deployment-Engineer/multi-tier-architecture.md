# Multi-Tier Architecture

## Two-Tier Architecture
A **Two-Tier Architecture** has two main parts:  
1. The **Web/Application Tier**  
2. The **Database Tier**

---

## Web/Application Tier
This part shows the user interface and handles requests from users. It takes care of the app logic and sends back the right response.

---

## Database Tier
This part stores data, like user accounts and records. It keeps the information safe, organized, and ready when needed.

---

## Why Separate Them?
Keeping the web server and database in different containers makes things easier to manage and safer. Each part can be updated or fixed without breaking the other, and they can use resources more efficiently. It also helps the system scale better when more users come in.
