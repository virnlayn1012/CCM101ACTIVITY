# Laboratory 10 – Enterprise Cloud Architect

## Project Overview
CloudNova is a cloud infrastructure project deployed using Ubuntu Server, VirtualBox, Docker, Docker Compose, WordPress, and MySQL.

## Technologies Used
- VirtualBox
- Ubuntu Server
- Docker
- Docker Compose
- WordPress
- MySQL
- UFW Firewall
- Bash Automation

## Project Components
1. architecture-diagram.png – System architecture diagram
2. docker-compose.yml – Multi-container configuration
3. automation-script.sh – Automated database backup script
4. operational-manual.md – System operation and maintenance guide
5. final-reflection.md – Project learning reflection
